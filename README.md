# App semestre filtro

App di studio per il semestre filtro di Medicina: lezioni guidate (studia, quiz, ripasso), animazioni interattive, errori spiegati e flashcard su chimica, biologia e fisica.

Si apre dal browser e, aggiunta alla schermata Home, funziona anche offline. I progressi restano salvati sul dispositivo.

## Studia Lezione

Secondo strumento nella cartella `studia-lezione`: carichi una registrazione o incolli il testo di una lezione e ottieni spiegazione, animazioni, appunti, flashcard e quiz (usa una chiave Gemini personale, salvata solo sul dispositivo).
